# Antigravity Daddy · 中转站对接契约（占位版 v0.3.0）

> 状态：**占位**。等你选定上游网站后再接。本文只约定「怎么接」，不改任何运行时行为。
> 当前边界（代码级事实）：**不代发请求、不代理流量、不统计用量、不分发密钥**。
> 已可用的只有两件事：连通性探测、契约字段清单。

---

## 一、现在就能用（无需接入）

| 能力 | 入口 | 行为 |
|---|---|---|
| 连通性探测 | 面板「中转站 → 检测连通性」 | 对填的地址发一次 `GET /`，再试一次 `GET /v1/models`；只读，不带业务请求 |
| 契约识别 | 同上 | 判断返回是否为 OpenAI 兼容 `data[]`，列出模型数与样例 |
| 契约字段清单 | 面板「中转站 → 查看对接契约」/ `GET /api/gateway/contract` | 返回字段名、是否必填、可用端点、边界声明 |
| 保存地址 | 面板「中转站 → 保存地址」 | 写入本机 `config.json` 的 `gateway.url` / `gateway.externalPort` |

本机 8045 若已跑 Antigravity Tools 反代，探测会显示在线；未跑显示未连接属正常，按「不重复造」处理。

## 二、配置字段（`%LOCALAPPDATA%\AGY-Daddy\config.json`）

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `gateway.enabled` | bool | `false` | 总开关。为 false 时**所有**中转站能力都不生效 |
| `gateway.url` | string | `''` | 服务根地址，**不带 `/v1`、不带尾斜杠**。例：`https://api.example.com` |
| `gateway.externalPort` | number | `8045` | 本机已有反代的探测端口（兼容旧配置保留） |
| `gateway.apiKey` | string | `''` | Bearer key。仅存本机 `config.json`，**不写日志、不回传**；探测时只发往你填的地址 |
| `gateway.protocol` | string | `openai` | `openai` \| `anthropic` \| `custom` |
| `gateway.modelMap` | object | `{}` | 官方模型 ID → 上游模型名 |
| `gateway.routing` | string | `quota` | `quota`（按余量挑池）\| `round-robin` \| `fixed` |
| `gateway.stats` | bool | `false` | 用量统计开关 |

修改方式（不改代码）：

```js
POST http://127.0.0.1:8787/api/settings
{ "gateway": { "url": "https://api.example.com", "apiKey": "sk-...", "protocol": "openai" } }
```

`POST /api/settings` 是浅合并，`gateway` 子对象会按字段合并，不会清掉其它项。

## 三、等你找到网站后的接入顺序

1. **先验契约**：面板填地址 → 「检测连通性」。确认 `openaiCompatible=true`、模型列表正确、Key 未被 401/403 拒。若网站不是 OpenAI 兼容，把 `protocol` 设为 `anthropic` 或 `custom`，并在第 3 步写适配分支。
2. **填配置**：按第二节写 `url` / `apiKey` / `protocol` / `modelMap`，此时 `enabled` 仍保持 `false`。
3. **实现适配层**（唯一需要写代码的地方）：新建 `src/gateway.js`，只做协议转换，不碰账号凭据、不碰官方 `Antigravity.exe`：
   - 入参：内部统一结构 `{ model, messages, stream, ... }`
   - 出参：上游响应归一化为内部结构；错误码与限流信息原样透出
   - 出入口各一处日志（只记状态码与耗时，**不记 key、不记正文**）
4. **点亮四个待接入项**（面板里现在是禁用态）：模型映射 → 路由策略 → 密钥管理 → 用量统计。逐项打开 `gateway.enabled`，一次只开一项，每开一项跑一次端到端验证。
5. **验收**：确认不影响其它 9 个页签；确认关闭 `gateway.enabled` 后所有转发立即停止。

## 四、服务端 API 现状（只读）

| 端点 | 方法 | 返回要点 |
|---|---|---|
| `/api/gateway/probe` | POST | `online`、`status`、`latencyMs`、`contract.{openaiCompatible,modelCount,models,authAccepted}`、`configured`、`note` |
| `/api/gateway/contract` | GET | `fields[]`、`endpoints[]`、`boundary`、`doc` |
| `/api/settings` | POST | 合并后的完整 `config` |

`/api/gateway/probe` 的 `contract` 探测只请求 `/v1/models`。若上游要求鉴权，把 `apiKey` 一起放在请求 body 或配置里；**该 key 不会被写入任何日志文件**。

## 五、明确不做（合规边界）

- 不修改、不替换官方 `Antigravity.exe` / `app.asar` / 签名；注入只存在于运行时 DOM。
- 不做设备指纹、不做风控规避、不绕过配额。
- 不代发用户业务请求，直到你显式把 `gateway.enabled` 打开并且适配层实现完成。
- 凭据只落本机：Credential Manager 原文 + 本项目 AES-256-GCM 加密副本；写前自动备份到 `backups\`。

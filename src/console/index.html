AD
Antigravity Daddy
版本 v0.3.0 · 独立 Web 控制台
不修改官方二进制
所有增强都在运行时生效，不触碰、不覆盖官方安装文件。
CDP 注入
通过 Chrome DevTools Protocol 向官方窗口注入面板，页面导航或客户端重启后自动重挂。
本地 RPC 桥
复用客户端自带的 LS RPC 读取配额与账号状态，不猜测云端接口、不代理业务流量。
本控制台与本地守护进程同源，由 127.0.0.1:8787 提供，所有数据仅在本机流转。
